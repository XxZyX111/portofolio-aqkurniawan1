- Personal introduction and biography

- Contact information and ways to connect
- Clear navigation and responsive design

## Tech Stack

This project was built using the following technologies:

- Frontend: `React`, `TypeScript`, `Vite`
- Styling: `Tailwind CSS`
- Project data: `GitHub REST API`
- Deployment: `Netlify`


## GitHub Project Sync

The Projects section reads directly from the public GitHub API for `XxZyX111`. It automatically displays the five newest owned, non-fork, non-archived repositories. When a newer repository is created, it appears at the top and the oldest item drops out of the five-project list.

No GitHub token is required for the current public-repository setup.

## Installation / Local Development

To run this portfolio locally, just follow the following steps:

1. Clone the repository  
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```
2. Change the directory
   ```bash
   cd YOUR_REPOSITORY
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Run developement server
   ```bash
   npm run dev
   ```
